# HNL club crests

These PNG files are cached locally so the game does not hotlink artwork during
play. The catalog club IDs correspond to the source club pages, and the exact
download URL and file size for each crest are recorded in `sources.json`.

Club names and crests are used only for nominative identification in this local
fan-made game. All club marks remain the property of their respective owners.
Their inclusion does not imply endorsement, affiliation, or licensing.
